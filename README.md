# Business Manager Suite

Application de gestion commerciale en Next.js et NestJS.

## Fonctionnalites

- Gestion des produits, prix d'achat, prix de vente et stock.
- Commandes fournisseurs avec montant engage et montant paye.
- Ventes avec prix variable par ligne, remise en montant ou en pourcentage.
- Paiements clients, avances et dettes restantes.
- Tableau de bord financier : montant depense, montant recu, benefice, dettes clients et benefice mensuel.

## Demarrage

```bash
npm install
npm run dev
```

- API NestJS : http://localhost:4000
- Interface Next.js : http://localhost:3000

La premiere version persiste les donnees dans `apps/api/data/db.json`.
